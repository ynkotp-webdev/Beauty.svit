## Direction contract

Выбрано владельцем на странице раздачи 2026-08-16. Бросок `concept-seed --scope direction --mode persuade`,
ключ `f83a1ac0`, ASSIGNED INDEX 5. Челленджеры каталога отклонены владельцем вместе с выходом «як прийнято в категорії».

**THESIS.** Сайт как карта відтінків: кожна послуга — пронумерований зразок із точною ціною, часом і тим, хто його виконує.

**OWN-WORLD.** Віяло колориста — ламінована палітра зразків, яку майстер розкриває біля обличчя клієнтки.
Матеріали: смуги-зразки справжніх кольорів з робіт салону, друкована шкала довжин 1–5, кодування рядків,
матовий картон. Не спа, не бутік, не барбершоп.

**STORY.** Жінка на Сихові о 22:40 порівнює три салони з телефона. Питання одне: скільки коштує саме мій
випадок і чи не додадуть на касі. Сайт відповідає її ж мовою вимірювання: довжина 1–5, ціна, хвилини,
ім'я майстра. Фарба включена — сказано першим екраном, а не дрібним шрифтом.

**FIRST VIEWPORT.** Вертикальні смуги-зразки справжніх робіт салону (мідь, червоне, каштан, мед, блонд)
розкриті віялом на всю висоту вікна. Поверх найтемнішої смуги — H1, під ним рядок фактів із реальними
числами, одна кнопка запису. Шкала довжин 1–5 читається як легенда зразка.

**FORM.** Асиметрія за замовчуванням, композиція за кодуванням зразка: номер — назва — довжина — ціна — час.
Жодна секція не повторює устрій попередньої більше одного разу.

## Surface contracts

Отдельные броски, по ключу на поверхность. `--from <key>` на каждую страницу механикой не поддержан —
`concept-seed` считает назначение из пары «ключ + scope + mode» и имени поверхности не принимает.

| Поверхность | Ключ | Индекс | Что строим |
|---|---|---|---|
| Прайс | `086ad121` | 5 | Разворот-сравнение: базовый уровень против уровня ТОП-майстра |
| Страница услуги | `b51a6f01` | 3 | Хронометраж как таймлайн визита |
| Запись | `69e34f5f` | 4 | Выбор мастера первым шагом |

**Прайс.** Назначение выдержало проверку на правду не сразу: линия Premium есть только у фарбування и
біозавивки, у 7 категорий из 12 второго уровня нет. Структура не переделывается, а разворачивается в
аргумент страницы: там, где второй колонки нет, честно написано «ціна одна, незалежно від майстра».
Салон делает надбавку только там, где работу физически выполняет другой человек, — и страница это показывает.

**Страница услуги.** Хронометраж есть у всех 108 позиций и в нише почти нигде не публикуется. Визит
разворачивается по времени: 0 хв — миття, далі процедура, на кінці результат. Порядок блоков
`page-anatomy.md#PLB-008` ложится на таймлайн без натяжки, попутно закрывается `PRICE-007`.

**Запись.** Вход через мастера, но путь «будь-який майстер, найближчий час» стоит рядом и равноправно —
`PLB-020`. Риск назван: фото мастеров нет, в CRM вместо портретов рисованные коты. Карточка держится
на имени, специализации, числе отзывов из CRM и работах этого мастера — это сильнее стокового лица,
но фото остаётся в списке к владельцу.

## North Star

**«Віяло зразків, а не вітрина».** Салон не уговаривает — он раскрывает палитру и даёт измерить себя.
Каждый экран отвечает на вопрос числом, а не эпитетом.

## Palette

Снята пикселями с реальных работ салона (`palette-from-photos.mjs` + точечная выборка тона волос в
кадре). Сегментный блок `design-tokens.md` не применялся: фото клиента сильнее.

| Токен | Hex | Роль | Откуда |
|---|---|---|---|
| `--paper` | `#EDEDEB` | фон страницы | стены и зеркала зала (#D8D8D8/#C0C0C0), осветлено |
| `--ink` | `#171716` | основной текст | #181818 |
| `--graphite` | `#242422` | фон инверсных секций | #303030 |
| `--ink-muted` | `#55554F` | вторичный текст | производное |
| `--sw-copper` | `#7A3312` | зразок «мідь», акцент, заливка CTA | photo_5, sat 86% |
| `--sw-red` | `#9A4030` | зразок «червоне» | photo_6 |
| `--sw-chestnut` | `#7A4A4A` | зразок «каштан» | photo_1 |
| `--sw-honey` | `#A08060` | зразок «мед» | photo_7, photo_9 |
| `--sw-blonde` | `#E8BC96` | зразок «блонд» | photo_11-05-55 |

**Пересчитанный контраст (WCAG 2.1 AA, порог 4.5:1):**

| Пара | Ratio | Вердикт |
|---|---|---|
| `ink` / `paper` | 15.30 | ✓ |
| `ink-muted` / `paper` | 6.40 | ✓ вторичный текст |
| `sw-copper` / `paper` | 7.76 | ✓ текст и CTA-заливка |
| `paper` / `sw-copper` | 7.76 | ✓ подпись на кнопке |
| `#FFFFFF` / `sw-copper` | 9.09 | ✓ |
| `sw-red` / `paper` | 5.69 | ✓ |
| `sw-chestnut` / `paper` | 6.16 | ✓ |
| `paper` / `graphite` | 13.27 | ✓ инверсная секция |
| `sw-blonde` / `graphite` | 8.93 | ✓ единственный светлый тон на тёмном |

**Запрещённые пары — только заливка зразка, никогда текст:**
`sw-blonde` / `paper` = 1.48 · `sw-honey` / `paper` = 3.11 · `sw-honey` / `graphite` = 4.26 ·
`sw-copper` / `graphite` = 1.71. Медь на тёмном не ставится вообще.

Текущий сайт для сравнения: контраст CTA 2.87:1 (`DES-007`, critical).

**Почему это не кластер генерации №1.** Тёплая медь рядом с антиквой на кремовом — самый частый исход
(`AIS-13`, `direction-roll.md`). Здесь расходится по трём точкам сразу: фон холодный нейтральный, а не
кремовый; дисплейная гарнитура — техничный гротеск, а не антиква; медь не «акцент бренда», размазанный
по нейтральному полю, а фотографический зразок работы салона, занимающий целые полосы. Убрать любую из
трёх — и проверка «угадывается ли эстетика по одной нише» перестаёт проходить.

## Typography

| Роль | Гарнитура | Вес |
|---|---|---|
| Дисплей и текст | **Geologica** (variable, wght 300–800) | 300/400/600/800 |
| Коды, номера зразків, довжина, хронометраж, ціна | **Martian Mono** (variable, wght 400–700) | 400/700 |

Обе с полной украинской кириллицей (ЄІЇҐ проверены по `cmap`), обе вне списка «дефолтных» `AIS-12` и вне
списка «вы перестали искать» от Impeccable.

Комплект: инстансированы через `fontTools.varLib.instancer` (Geologica — CRSV/SHRP/slnt зафиксированы),
субсет «кириллица + базовая латиница + пунктуация», woff2.
**19.8 КБ + 12.5 КБ = 32.2 КБ** при бюджете 70 КБ (`DES-010`). Текущий сайт — 175.6 КБ.

## Devices

Пять приёмов из `design-devices.md`, больше не берём.

1. **DEV-04 — меню строками вместо сетки карточек.** Услуги и прайс — строки с волосяной линейкой:
   номер зразка, название, довжина слева; цена моношрифтом и «Обрати час →» справа. Прямая замена
   самого частого AI-паттерна и одновременно буквальная форма карты образцов. Класс `service-card`
   сохраняется — по нему меряет `STRUCT-009`.
2. **DEV-05 — прайс как меню, а не таблица данных.** Без зебры и рамок, якоря разделов — текстовые
   ссылки с подчёркиванием, не pill-чипы (`AIS-07`).
3. **DEV-07 — мозаика `columns` для работ.** Снимки клиента идут в двух пропорциях (0.75 и 1.33) —
   мозаика сохраняет их как есть, вместо приведения к одинаковым квадратам. У каждого `img`
   проставлены `width`/`height` под CLS ≤0.05.
4. **DEV-11 — моноширинная подпись.** Номера зразків, довжина, хвилини, ціна. Надзаголовок отдельным
   блоком над каждым H2 **не ставится** — это `AIS-09`, ловится `detect` как `kicker-above-heading`.
5. **DEV-14 — инверсная секция.** Одна-две секции на `graphite`: команда и финальный CTA. Контраст
   пересчитан заново, медь на тёмный не выносится.

**Подпись первого экрана — собственный приём мира, а не `DEV-01`.** Широкого кадра зала у клиента нет
ни одного: все 15 своих снимков вертикальные или почти квадратные, максимум 1280px по ширине.
Полноширинное фото поверх текста поэтому физически недостижимо честным путём. Вместо него — веер
вертикальных полос-образцов: формат 0.75 работает на них не вопреки, а по назначению. Текст ложится
на самую тёмную полосу с гарантированной подложкой, пиксельный контраст проверяется `impeccable detect`,
а не глазом.

## Rejected

Явно отвергнуто и почему:

- **DEV-01** (фото во всю ширину) — нет ни одного широкого кадра зала. Заменено веером полос.
- **DEV-02** (заголовок в два веса и два цвета) — веер уже несёт цвет; заголовок в две краски поверх
  цветных полос читается как шум.
- **DEV-03** (строка фактов вместо второй кнопки) — числа есть, но их место в легенде зразка под H1;
  отдельная полоса дублировала бы её.
- **DEV-06** (плитка `gap-px`), **DEV-12** (скошенная плашка), **DEV-13** (уголковые скобки) — характер
  уже задан кодированием зразка; ещё один графический приём поверх сделал бы страницу декоративной.
- **DEV-08** («до/після» со слайдером) — нет ни одной пары одинаковой съёмки. Выдумывать нельзя.
- **DEV-09** (drag-карусель мастеров) — нет фото мастеров.
- **DEV-10** (видео-отзыв) — видео нет. Отзывы сводятся к ссылкам на первоисточники (`PLB-071`).
- **Кремовый фон** (`AIS-10`), **split-hero 50/50** (`AIS-05`), **три карточки в ряд** (`AIS-06`),
  **pill-чипы** (`AIS-07`), **контейнер 1200px по центру** (`AIS-08`), **кикер над каждым H2** (`AIS-09`).
- **Чужие фото с текущего сайта** — примерно половина картинок там из Pinterest. Не переносится ни одна.
- Параллакс, «стеклянные» карточки, градиентный текст, анимация появления каждого блока при скролле.

## Motion

Точечная: 150–250 мс, состояние наведения на строке услуги и открытие модалки записи. Всё под
`prefers-reduced-motion`. Раскрытие веера на первом экране — статичная композиция, не анимация.

## Layout rules

- Контейнера 1200px по центру нет. Доли колонок 0.8fr/1.2fr и 1fr/2fr, фото уходит за край секции.
- На странице из 8 секций не более двух одинаковых по устройству (`DIR-04`), минимум одна инверсная.
- Мобильный первым: строка услуги складывается в два уровня, проверяется на 320px.
- Тач-цели ≥44×44px. На текущем сайте 55 из 94 меньше (`MOB-002`).
